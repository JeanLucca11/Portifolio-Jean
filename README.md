# Portfólio — Jean Lucca

Meu portfólio pessoal, desenvolvido para apresentar meus projetos
e aprofundar meus conhecimentos em desenvolvimento web.

🔗 [Acesse o portfólio](https://jeanlucca11.github.io/Portifolio-Jean/)

## Funcionalidades

- Layout responsivo para computadores e celulares.
- Alternância entre tema escuro e claro.
- Armazenamento da preferência de tema no navegador.
- Seções de habilidades, projetos e contato.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git e GitHub
- GitHub Pages para hospedagem

## Aprendizados

Durante o desenvolvimento, pratiquei:

- Estruturação de páginas com HTML semântico.
- Estilização com variáveis CSS, Flexbox e Grid.
- Adaptação do layout com media queries.
- Manipulação do DOM e tratamento de eventos.
- Uso do localStorage.
- Versionamento com Git e publicação com GitHub Pages.

## Meu Objetivo

- Através desse projeto de portifólio pessoal eu gostaria de aprimorar meus conhecimentos sobre o desenvolvimento Web e buscar oportunidades no mercado de trabalho dentro dessa área.

## Como executar localmente

1. Clone este repositório:

   ```bash
   git clone https://github.com/JeanLucca11/Portifolio-Jean.git
   ```

2. Abra a pasta baixada.
3. Abra o arquivo `index.html` no navegador.

O projeto não exige instalação de dependências.
